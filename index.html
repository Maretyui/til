Today I Learned — short notes, one per day.

  • Discord Components V2 messages can't carry a top-level content field Discord bots — a ping/mention text silently disappeared after switching to Components V2 cards; fixed by sending the mention as its own plain message first
  • Rspamd silently drops internal relay mail that claims a local domain in From: without SASL auth infra — a mailing list's redistributed copies vanished with no bounce; fixed by allowlisting the relay's source IP in Rspamd's forwarding-host map
  • ufw's CIDR-scoped allow and an unscoped deny for the same port don't behave like rule order implies infra — an allow-from-CIDR + deny-all pair for SSH locked out both trusted and untrusted clients; scoping both rules by interface instead fixed it
  • An inline object in a useEffect dependency array reruns the effect every render web dev — useEffect compares dependencies by reference (Object.is), so a literal {a, b} built in the render body never matches the previous one
  • cron runs jobs with a stripped-down PATH, not your login shell's infra — a script that "works when I run it" failed under cron because cron never sources .bashrc/.profile at all
  • A fresh Postgres database is connectable by every role on the cluster unless you revoke it infra — CREATE DATABASE grants CONNECT to PUBLIC by default, so "one database per app" isn't isolated until you revoke it explicitly
  • pm2 restart keeps the environment from the first pm2 start, not the current shell infra — a rotated SMTP password never took effect until --update-env forced PM2 to re-capture the env on restart
  • Re-signing an Android app with a different keystore makes the OS treat it as a different app mobile — switching a gomobile build from debug-signed to a real release keystore breaks in-place install with a bare "App not installed"
  • A settings-page field for TRUSTED_PROXIES doesn't mean it's actually wired up infra — a Laravel panel saved the setting but bootstrap/app.php never called trustProxies(), breaking signed URLs behind the reverse proxy
  • A client-only boot overlay defaulting to hidden flashes the real page for one frame web dev — a mounted-state overlay starting false matches on server and first client paint, so nothing hides the page until the useEffect fires
  • A root-owned log file can make every later error look inexplicably generic infra — running an admin command as root instead of the service user broke the framework's own error logging, masking the real bug
  • ufw can scope a port to one source IP instead of opening it to the whole internet infra — allow from <ip> to any port <N> keeps a proxy-only port from being reachable directly by anyone
  • fail2ban's auto backend detection silently fails to find sshd logs on older versions infra — an older fail2ban's log-backend auto-detection never started the sshd jail, no error, just silence
  • Tailwind v4's spacing scale accepts decimals like w-4.5, no brackets needed web dev — a calc()-based spacing scale makes fractional utilities real classes, not typos or arbitrary values
  • Wings derives its websocket CORS origin from its own config, not the node's Minecraft admin — infra — a scheme mismatch in Wings' own remote: field silently 403'd the live console
  • An LXC container's runaway process can freeze the whole Proxmox host infra — Minecraft admin — an item duper's memory spike took down every guest on the host, not just that one container
  • Nginx Proxy Manager deletes a proxy host's config if regeneration fails infra — a failed nginx -t on regenerate leaves no config on disk at all, silently, with no UI warning
  • Fyne's Storage.Save() errors if the file doesn't exist yet mobile dev — an upsert-sounding API call that's actually create-only-if-already-there, needs a Create() fallback
  • Discord interactions expire in 3 seconds, defer before slow calls Discord bots — a channel-rename rate limit blew past the ack window and 404'd the reply
  • nginx doesn't dedupe repeated proxy_set_header in the same block infra — a reused Host header alongside an include sent a duplicate on the wire and 400'd
