  • A systemd calendar timer silently skips runs missed while the machine was off infra — OnCalendar= only fires while something is watching the clock; Persistent=true makes it catch up once on the next boot instead of waiting for the next regular slot
  • Discord's rate-limit Retry-After value is seconds, not milliseconds Discord bots — both the HTTP header and the 429 body's retry_after field are already seconds; multiplying either by 1000 a second time turns a short cooldown into a very long one
  • fetch() only rejects on network failure, never on an HTTP error status web dev — a 404 or 500 response still resolves the promise successfully; only res.ok/res.status tells you the request actually failed
  • Discord autocomplete interactions can't be deferred like other interactions Discord bots — autocomplete has no deferred-response type, so a slow lookup just makes the suggestion dropdown silently stay empty instead of erroring
  • A Discord embed has a character limit per field, not just one overall limit Discord bots — field.value caps out at 1024 characters well before the embed's combined 6000-character budget, so a value that clears the "total" mental limit can still fail on its own
