  • Pelican's server build endpoint 500s on limit-only edits unless you also resend the allocation infra — PATCH .../build reads allocation unconditionally while assembling the update, so omitting it on a pure memory/cpu/disk change throws before the real fields are ever touched
  • Fyne's Android debug build hardcodes an old targetSdkVersion, triggering a scary install warning dev tooling — fyne-cross's debug signing mode pins targetSdkVersion=29 regardless of the real SDK installed; -release mode fixes it but needs a real keystore and outputs an .aab, not an APK

  • Rspamd silently drops mailing-list redistribution unless the list server's IP is forwarding-allowlisted infra/mail — a resent message keeps the original From:, which Rspamd's SPOOFED_UNAUTH composite treats as spoofing unless the relaying host is explicitly allowlisted as a trusted forwarder
  • WordPress's WP_SITEURL/WP_HOME constants silently override the DB options of the same name web dev — a defined constant wins over wp_options unconditionally, and wp option get reads back the effective (constant) value, making a successful-looking DB update a no-op
  • Next.js's Metadata API resolves relative Open Graph images against localhost without metadataBase web dev — a missing metadataBase silently resolves relative openGraph/twitter image paths against localhost:3000 in production, breaking link previews
  • ufw's rule order doesn't behave the same for CIDR-scoped and interface-scoped rules infra — an unscoped deny beat a CIDR-scoped allow on one host and locked out SSH entirely, interface-scoped rules fixed it
  • SQLite in WAL mode still needs a busy_timeout under real concurrent writes infra/SQLite — WAL mode solves readers-vs-writer blocking, not writer-vs-writer; a real busy_timeout is what turns a lock collision into a retry instead of a crash
  • An LLM asked to "pick a random number" converges on the same number automation — sampling from a prompt isn't sampling from a distribution; generate real randomness outside the model ($RANDOM, shuf) and hand it in as a fixed instruction instead
  • discord.js guild command registration 403s if the bot isn't in the guild yet Discord bots — guild-scoped slash command registration needs the bot to already be a member of that guild; the fix is the OAuth invite, not a token/permission change

  • docker compose --force-recreate wipes anything installed into a container's writable layer infra/Docker — named volumes and bind mounts survive a recreate, but a curl-installed binary or by-hand apt install inside the container itself doesn't
  • Fyne's default canvas.Image scale mode redoes CPU resampling on every repaint Go/Fyne — mobile perf — ImageScaleSmooth bilinear-resamples a full-screen background on every frame; ImageScaleFastest hands scaling to the GPU instead, a strict win on both mobile and desktop

  • Redis EXPIRE applies to the whole key, not individual hash fields infra — setting a TTL on a hash after HSET-ing one field expires every field in that hash, not just the one just written

  • A stray --radius-*: initial; in a Tailwind v4 @theme block crashes Turbopack's dev server web dev — a Rust-level "every task must have a task type" panic surfaced as an unrelated component-handler 500; removing the CSS reset line fixed it, no cache clear needed
