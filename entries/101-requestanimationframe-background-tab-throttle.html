A step sequencer's timing drifted by seconds after switching tabs

A little web-audio step sequencer tracked elapsed time with performance.now() deltas read inside a requestAnimationFrame loop, used both to advance the playhead and to schedule the next note. Switching to another tab for a minute and coming back left the sequencer wildly behind where the audio clock actually was, as if it had been paused the whole time.

Why: a backgrounded tab throttles rAF down to roughly once a second

requestAnimationFrame callbacks are tied to the page actually painting. Once a tab is backgrounded, most browsers stop painting it and throttle its rAF queue to about 1 call/second (some go lower, or stop it entirely) to save battery and CPU. Any timing logic that assumes "this callback fires every ~16ms" silently breaks the moment the tab loses focus — the callback still runs, just far less often, so a delta computed between calls balloons. 

// Looks fine while the tab is focused, drifts hard once backgrounded
let last = performance.now();
function tick(now) {
  const dt = now - last; // can be ~1000ms+ after a background gap
  last = now;
  advanceSequencer(dt);
  requestAnimationFrame(tick);
}
requestAnimationFrame(tick);

// Anchor to wall-clock time instead of trusting rAF's call frequency
const startedAt = performance.now();
let stepsPlayed = 0;
function tick(now) {
  const elapsed = now - startedAt;
  const stepsDue = Math.floor(elapsed / stepDurationMs);
  while (stepsPlayed < stepsDue) {
    playStep(stepsPlayed);
    stepsPlayed++;
  }
  requestAnimationFrame(tick);
}

The actual lesson

Treat requestAnimationFrame purely as a signal to re-render, never as a metronome. Anything that has to stay correct across a backgrounded tab — audio scheduling, countdowns, game state — needs to compute "where should we be right now" from an absolute timestamp (or the Web Audio clock, which keeps running regardless of tab visibility) and catch up in one jump, instead of accumulating a per-frame delta that assumes frames arrive on a regular schedule.
